# tmap — карта трафика машины в терминале

`tmap` показывает живой сетевой трафик этой машины на карте мира прямо в терминале:
береговая линия в Braille-графике, ваша точка «я», удалённые пиры и кометы, летящие по
дугам больших кругов в обе стороны. Каждое соединение и каждый всплеск трафика порождают
комету: зелёная — исходящая, голубая — входящая. Внизу — суммарные скорости, число
потоков, страны и самые активные процессы. Никакого браузера и никакого веб-сервера:
всё считается локально из сокетов машины.

## Пример

Обычный режим рисует карту символами Braille (U+2800). Ниже — тот же кадр в режиме
`--ascii` (см. [Диагностику](#диагностика)): он годится для терминалов без шрифта
с Braille-глифами.

```
                    ###### ########
           ##########################    #####  #######  ######## #  ####
####################################     #####################################
########################## ####  --+ ## ########################################
  ###    ###################        ####O##############################  ###
           #################        ####################################
           +###########             ###################################
   ##        #########             ###############################
    #          ##########          ################## ########## ##
                   #########       ################    ###  #######
                     ##########         ##########          ########### #
                     ###########         ####### #           ######--######
↑ 1.2 MB/s   ↓ 9.1 MB/s   flows 4   peers 4   local 1   unknown 1   US AU
firefox:443 ↓9.0 MB/s · curl:443 ↑1.2 MB/s · unknown:53 ↓101.0 KB/s
no root: only your sockets · anchor 198.51.100.42 · NL · geo 0ms
```

В ASCII-режиме: `#` — суша, `*` — пир (удалённый адрес), `+` — голова кометы,
`-` — след кометы, `O` — ваша точка «я», пробел — море. Цвета те же самые: суша тёмно-синяя,
пиры жёлтые, исходящие кометы зелёные, входящие голубые.

Подробный справочник — в [docs/usage.md](docs/usage.md).

## Требования

- **Linux** — программа читает сокеты командой `ss -t -u -a -i -n -p` (пакет `iproute2`).
- **Python ≥ 3.11** (проверено на 3.14.7).
- **`ss`** из `iproute2`: `sudo apt install iproute2` / `sudo dnf install iproute`.
- **~130 МБ баз GeoIP** — они скачиваются командой `make assets` (DB-IP Lite City — 121 МиБ,
  DB-IP Lite ASN — 9 МиБ) и лежат в каталоге `assets/`.
- Шрифт терминала с Braille-глифами (U+2800). Нет такого шрифта — запускайте с `--ascii`.

## Установка

```bash
cd ~/Projects/traffic-map
make venv      # создаёт .venv и ставит пакет с зависимостями
make assets    # скачивает базы GeoIP и карту суши в assets/
```

`make assets` кладёт в `assets/` три файла:

| Файл | Размер | Что это | Лицензия |
|---|---|---|---|
| `dbip-city-lite.mmdb` | ~121 МиБ | DB-IP Lite City: страна, город, координаты | CC BY 4.0 |
| `dbip-asn-lite.mmdb` | ~9 МиБ | DB-IP Lite ASN: номер и имя автономной системы | CC BY 4.0 |
| `land.geojson` | ~135 КБ | Natural Earth 110m land: полигоны суши | public domain |

Скрипт скачивает свежую публикацию месяца, а если её ещё нет — публикацию прошлых месяцев
(до трёх назад). Уже скачанные и валидные файлы не перекачиваются, повторный запуск безопасен.

### Пакет ставится из исходников

Пути к базам и к карте суши по умолчанию считаются от исходников пакета:
`src/trafficmap/config.py` берёт `Path(__file__).resolve().parents[2] / "assets"`.
Поэтому программу нужно ставить **в режиме редактирования** — именно это делает
`make venv` (`pip install -e '.[dev]'`), и именно из этого каталога её и запускают.

Обычный `pip install .` копирует пакет в `site-packages`, и пути по умолчанию уезжают
в `site-packages/assets`, где баз нет: программа скажет `city database not found`.
Лечится либо установкой через `make venv`, либо явными путями
(`--city-db`, `--asn-db`, `--land-geojson` или те же ключи в `config.toml`).

### Остальные цели Makefile

| Цель | Что делает |
|---|---|
| `make venv` | создаёт `.venv` и ставит пакет с зависимостями в режиме редактирования |
| `make assets` | скачивает базы GeoIP и карту суши в `assets/` |
| `make test` | прогоняет тесты (`pytest`) |
| `make lint` | проверяет, что все модули компилируются (`compileall`) |
| `make check` | `lint` и `test` вместе |
| `make snapshot` | рисует кадр карты в `/tmp/tmap.txt` (без терминала) |
| `make run` | запускает программу из исходников |

## Запуск

```bash
sudo .venv/bin/tmap                          # живая карта, видны сокеты всех процессов
.venv/bin/tmap --mock tests/fixtures/mock.jsonl   # демо без сети и без root
.venv/bin/tmap --dump out.jsonl               # headless-режим: потоки в JSONL
.venv/bin/tmap --snapshot frame.txt --frames 30   # один кадр карты в файл
.venv/bin/tmap --version                      # версия программы
.venv/bin/tmap --help                         # список всех ключей
```

- **С `sudo`** программа видит сокеты всех процессов машины. **Без root** `ss` показывает
  только ваши собственные сокеты — программа предупредит об этом жёлтой строкой
  `no root: only your sockets` в статус-баре.
- **`--mock`** переигрывает запись сокетов (`tests/fixtures/mock.jsonl`): сеть не нужна,
  root не нужен, карта воспроизводится одинаково при каждом запуске. Нужны только базы
  GeoIP из `assets/`.
- **`--dump`** пишет события потоков в JSONL, по одному объекту на строку, без curses.
  Останавливается по `Ctrl-C` или `SIGTERM` (код возврата 0).
- **`--snapshot`** рисует `--frames` кадров без терминала и записывает последний в файл
  обычным текстом. Это то, чем проверяется программа в тестах.
- **`--version`** печатает версию и выходит.
- **`--help`** печатает список ключей и выходит.
- **`--verbose`** включает журнал программы: сообщения идут в `stderr`, а не в
  стандартный вывод, — карта на экране от этого не портится. Нужен, чтобы понять,
  почему опрос сокетов падает.

## Сеть и первый запуск

К сети программа ходит **один раз** — чтобы узнать публичный адрес машины
(точка «я» на карте):

- `https://api.ipify.org`, а если он не ответил — `https://ifconfig.me/ip`;
- весь поиск (оба сервиса) укладывается в 2 секунды;
- ответ кэшируется в `~/.cache/trafficmap/anchor.json` на час, так что следующий
  запуск уже без сети;
- `--no-anchor` (или `no_anchor = true` в конфиге) отключает поиск совсем; точку «я»
  можно задать руками: `--anchor 52.37,4.90`.

Больше никуда программа не ходит: геолокация адресов читается из локальных баз GeoIP,
а не из сети.

При **первом** запуске карта суши растеризуется в растр нужного размера и кладётся
в кэш (`~/.cache/trafficmap/land_*.bin`), поэтому первый кадр появляется через пару
секунд. Дальше растр берётся из кэша и карта рисуется сразу. После смены размера
терминала растр для нового размера строится заново — это тоже несколько секунд.
Первый запуск без `sudo` или с `--no-anchor` идёт быстрее: якорь искать не нужно.

## Клавиши

| Клавиша | Что делает |
|---|---|
| `q` | выход |
| `space` | пауза: карта замирает, сбор трафика продолжается |
| `t` | панель самых активных потоков |
| `l` | подписи стран у пиров |
| `1` `2` `3` | зум: весь мир → 120°×60° → 30°×20° (центр — ваша точка) |
| `f` | фильтр по имени процесса (пустая строка — фильтр снят, `Esc` — отмена ввода) |
| `Esc` | снять фильтр: на карте снова все потоки |
| `?` | панель со списком клавиш |

## Настройки

Приоритет: **командная строка** > **переменные `TMAP_*`** > **`config.toml`** > значения по
умолчанию.

Конфиг лежит в `~/.config/trafficmap/config.toml` (путь можно переопределить через
`XDG_CONFIG_HOME`). Неизвестный ключ — ошибка с внятным сообщением.

```toml
# ~/.config/trafficmap/config.toml
fps = 12                 # кадров в секунду
poll_ms = 1000           # как часто опрашивать сокеты
ascii = false            # рисуть карту обычными символами, без Braille
no_anchor = false        # не искать публичный IP этой машины
filter_process = ""      # показывать только потоки этого процесса
cache_dir = "~/.cache/trafficmap"
city_db = "assets/dbip-city-lite.mmdb"
asn_db = "assets/dbip-asn-lite.mmdb"
land_geojson = "assets/land.geojson"
```

Те же параметры можно задать переменными окружения: `TMAP_FPS`, `TMAP_POLL_MS`,
`TMAP_ASCII`, `TMAP_NO_ANCHOR`, `TMAP_FILTER_PROCESS`, `TMAP_CACHE_DIR`, `TMAP_CITY_DB`,
`TMAP_ASN_DB`, `TMAP_LAND_GEOJSON`, `TMAP_ANCHOR`, `TMAP_MOCK`, `TMAP_SNAPSHOT`,
`TMAP_FRAMES`, `TMAP_DUMP`.

Ключи командной строки:

| Ключ | Смысл |
|---|---|
| `--fps N` | кадров в секунду (по умолчанию 12) |
| `--poll-ms MS` | интервал опроса сокетов (по умолчанию 1000) |
| `--ascii` / `--no-ascii` | карта обычными символами вместо Braille |
| `--no-anchor` / `--resolve-anchor` | не искать (или искать) публичный IP машины |
| `--anchor LAT,LON` | задать точку «я» вручную |
| `--filter-process NAME` | показывать только потоки процесса |
| `--city-db PATH` | файл базы городов (MMDB) |
| `--asn-db PATH` | файл базы автономных систем (MMDB) |
| `--land-geojson PATH` | файл полигонов суши (GeoJSON) |
| `--cache-dir PATH` | каталог кэша (растр суши, кэш якоря) |
| `--mock PATH` | переигрывать запись сокетов вместо `ss` |
| `--dump PATH` | headless-режим: писать потоки в JSONL |
| `--snapshot PATH` | записать последний кадр карты в файл |
| `--frames N` | сколько кадров отрисовать для `--snapshot` |
| `--version` | напечатать версию и выйти |
| `--verbose` | писать журнал программы в `stderr` |

## Ограничения

- **Объём UDP не виден.** В `ss` у UDP-сокетов нет счётчиков байт, поэтому DNS и QUIC
  только «мигают» на карте, но не показывают скорость.
- **Короткие соединения теряются.** Опрос идёт раз в секунду: соединение, которое
  открылось и закрылось между двумя опросами, может не попасть в кадр.
- **Город в базе неточен.** Датацентры и VPN отдают координаты соседнего города;
  надёжнее страна и номер автономной системы.
- **Тихие пиры прячутся.** Поток, который не передал ни байта дольше 5 секунд, уходит с
  карты (но остаётся в таблице и может вернуться).
- **Ошибка опроса не убивает программу.** В статус-баре появляется баннер
  `collector error: ...`, последние собранные данные остаются на экране, а опрос
  повторяется с задержкой от 1 до 5 секунд.

## Диагностика

- **Нет Braille-глифов** (квадратики вместо карты) — шрифт терминала без блока U+2800.
  Запустите с `--ascii`.
- **`city database not found`** — не скачаны базы GeoIP: выполните `make assets`.
  Если программа ставилась обычным `pip install .`, а не из исходников, — укажите пути
  руками (см. «Пакет ставится из исходников»).
- **Пустая карта** — проверьте строку `anchor ...` в статус-баре: без якоря нет ни дуг, ни
  точки «я». Также проверьте, что `ss` вообще что-то показывает (`ss -tunap`).
- **`collector error: ...`** — опрос сокетов падает. Причина — в журнале: запустите с
  `--verbose`, сообщения придут в `stderr`.
- **Первый кадр идёт долго** — растеризуется карта суши, она кладётся в кэш
  `~/.cache/trafficmap/`; следующие запуски быстрые.
- **Программа тормозит** — уменьшите окно терминала или частоту кадров (`--fps 5`).
- **Программа не запускается в фоне** — TUI нужен настоящий терминал: из cron или
  systemd-юнита без `TTYPath` curses не получит экран (см. `trafficmap.service`).
