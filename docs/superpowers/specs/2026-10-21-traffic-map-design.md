# Traffic Map (TUI) — дизайн

**Дата:** 2026-10-21
**Статус:** утверждён
**Проект:** `~/Projects/traffic-map`
**Команда:** `tmap`

## 1. Цель

Показывать живой сетевой трафик этой машины на карте мира прямо в терминале: береговая
линия в Braille-графике, точка «я», удалённые пиры и кометы, летящие по дугам больших
кругов в обе стороны. Никакого браузера, никакого web-сервера.

Успех: запустил `sudo tmap` — через пару секунд видно, как пакеты уходят и приходят,
видно процессы, страны и текущие скорости.

## 2. Не-цели

- Web UI, глобус на three.js, ntopng.
- DPI, разбор payload, SNI, доменные имена (только IP/ASN/PTR).
- Историческая база, графики за сутки, экспорт метрик.
- Кроссплатформенность: только Linux (netlink/`ss`, `/proc`).
- Управление трафиком, шейпинг, блокировки.

## 3. Пользовательский сценарий

1. `sudo tmap` (root нужен, чтобы видеть сокеты всех процессов).
2. В статус-баре `anchor: 203.0.113.7 · RU` — геолокация точки «я».
3. Каждое новое соединение/всплеск трафика порождает комету: зелёная — исходящая,
   голубая — входящая. Комета летит по great circle, за ней гаснущий след.
4. Активные пиры — точки (одна точка на удалённый адрес), гаснут через 10 с тишины.
   Скорость потока задаёт вес пира, но размер точки от неё не зависит.
5. Внизу: суммарные ↑/↓, число флоу, стран, топ-процессы.
6. `q` — выход, `space` — пауза (карта замирает, сбор продолжается), `t` — панель
   топ-талкеров, `l` — подписи стран, `1/2/3` — зум, `f` — фильтр по процессу,
   `Esc` — снять фильтр.

## 4. Архитектура

```
┌──────────────────────── collector thread (1 Гц) ────────────────────────┐
│  ss -t -u -a -i -n -p  →  parse_sockets()  →  list[SocketRow]           │
│        │                                              │                 │
│        │                    GeoResolver (MMDB)  ←─────┘                 │
│        ▼                                              ▼                 │
│   FlowTable.update(rows, now) ──► events: Opened / Delta / Closed       │
└───────────────────────────────────┬─────────────────────────────────────┘
                                    │ queue.Queue
┌───────────────────────────────────▼─────────────── UI thread (12 fps) ──┐
│  Animator: Comet / Peer  →  Canvas (Braille, styles)                    │
│  Viewport (equirectangular, zoom) →  curses screen + status bar         │
└─────────────────────────────────────────────────────────────────────────┘
```

Компоненты изолированы: коллектор не знает про curses, рендерер не знает про `ss`,
геолокация не знает ни про то, ни про другое. Всё, что можно посчитать без терминала,
тестируется без терминала.

### 5.2 `geo.py`

```python
@dataclass(frozen=True, slots=True)
class Geo:
    ip: str
    lat: float | None
    lon: float | None
    country: str          # ISO alpha-2 или "--"
    city: str | None
    asn: int | None
    org: str | None

class GeoResolver:
    def lookup(self, ip: str) -> Geo: ...
    def anchor(self) -> Geo | None: ...
```

- MMDB: DB-IP Lite City + ASN. Поля: `country.iso_code`, `city.names.en`,
  `location.latitude/longitude`, `autonomous_system_number/organization`.
- Формат базы: маркер `\xab\xcd\xefMaxMind.com` находится **в конце файла**, в секции
  метаданных, а не в начале: при проверке скачанного файла маркер ищется в последних
  128 КиБ (секция метаданных не длиннее этого).
- Приватные и служебные диапазоны — явный список сетей (`10/8`, `172.16/12`,
  `192.168/16`, `100.64/10`, `127/8`, `169.254/16`, `fc00::/7`, `fe80::/10`, `::1/128`),
  а не `is_private` (он не покрывает CGNAT стабильно). Такие адреса на карту не идут,
  считаются в счётчик `local`.
- Anchor: публичный IP через `https://api.ipify.org` (fallback `https://ifconfig.me/ip`),
  затем `lookup()`. Весь поиск (оба сервиса) укладывается в **общий бюджет 2 с** — не
  2 с на запрос: ответивший поздно сервис бесполезен. Кэш `cache_dir/anchor.json`,
  TTL 1 час.
- Файл кэша якоря проверяется перед использованием: IP должен быть адресом, координаты —
  конечными числами в диапазоне (широта ±90, долгота ±180). Сломанный файл игнорируется.
- IP не найден в базе → `lat/lon = None`, точка не рисуется, страна `--`.
- Если сеть недоступна — anchor из конфига; если и его нет — режим «только точки»,
  в статус-баре `anchor: unknown`.

### 5.3 `projection.py`

Равнопромежуточная (equirectangular) проекция. Viewport: центр, ширина/высота в градусах.

```python
def project(lat: float, lon: float, vp: Viewport) -> tuple[int, int] | None
def unproject(x: int, y: int, vp: Viewport) -> tuple[float, float]
def great_circle(a: tuple[float, float], b: tuple[float, float], n: int) -> list[tuple[float, float]]
```

Great circle — slerp по единичным векторам:

```
p(t) = (sin((1-t)Ω)·a + sin(tΩ)·b) / sin Ω,  Ω = acos(a·b)
lat = asin(z), lon = atan2(y, x)
```

При `Ω < 1e-9` — линейная интерполяция. Для антиподов (`sin Ω ≈ 0`) — через
ортогональный вектор. Тесты: Москва→Нью-Йорк, середина пути в Атлантике.

### 5.4 `braille.py`

Точечная сетка, 2×4 точки на знакоместо. Битовая карта:

```python
BITS = ((0x01, 0x08),
        (0x02, 0x10),
        (0x04, 0x20),
        (0x40, 0x80))   # BITS[y][x]
```

`Canvas` хранит `bytearray` стилей на каждую точку (`0` — пусто). Стиль знакоместа —
максимум по его 8 точкам (так комета перекрывает сушу, суша — фон). Методы:
`set`, `line` (Брезенхем), `blit_land`, `clear` (стереть все точки), `dot_style`
(стиль одной точки), `cell_styles() -> list[list[int]]` (список списков, по строке на
знакоместо), `rows() -> list[str]` (текст знакомест). Символ: `chr(0x2800 | mask)`.

Точка хранит **максимальный** стиль, который в неё писали: тусклый элемент никогда не
затирает яркий (стиль `0` — no-op, точку нельзя стереть). Стили знакоместа — тоже
максимум по его точкам.

Стили (числа = приоритет): `1 land`, `2 trail_dim`, `3 trail_mid`, `4 peer`,
`5 trail_bright`, `6 comet_head`, `7 anchor`.

### 5.5 `worldmap.py`

- Источник: Natural Earth 110m land GeoJSON (~200 КБ, public domain).
- Растеризация: Pillow `Image.new("1", (W, H))` + `ImageDraw.polygon` для каждого
  полигона, `getdata()` → `bytearray` 0/1. `W×H` — размер точечной сетки.
- Кэш: `cache_dir/land_{W}x{H}_{mtime}.bin`; при старте/ресайзе сначала кэш,
  иначе растеризация (~30–100 мс).
- Внутренние кольца полигонов не рисуются: у набора 110m ровно одна дырка — Каспийское
  море (внутреннее кольцо фичи 112), поэтому Каспий нарисован как суша.
- Тест: доля суши 20–45 %. Равнопромежуточная сетка растягивает полюса, и одна только
  Антарктида занимает около шестой части сетки: доля суши заметно выше 29 % реальной
  поверхности и уменьшается с ростом разрешения (0.41 на 160×80, 0.37 на 320×160,
  0.35 на 720×360). Проверяется также, что центр Африки — суша, а центр Тихого океана —
  вода.

### 5.6 `collector_ss.py`

```python
@dataclass(frozen=True, slots=True)
class SocketRow:
    proto: str                  # "tcp" | "udp"
    local: tuple[str, int]
    remote: tuple[str, int]
    state: str
    pid: int | None
    process: str | None
    bytes_sent: int | None
    bytes_received: int | None
    key: str

def parse_sockets(text: str) -> list[SocketRow]
class SsCollector:
    def poll(self) -> list[SocketRow]
```

- Команда: `ss -t -u -a -i -n -p` (argv, без shell).
- Парсинг: заголовок пропускаем; строка сокета → поля; последующие строки с отступом —
  `bytes_sent:`, `bytes_received:` (tcp_info; у UDP обычно нет — тогда `None`).
- IPv6 `[2001:db8::1]:443`, зоны `%eth0` отбрасываем.
- Отбрасываем: `LISTEN`, remote `0.0.0.0`/`::`/`*`, state `TIME-WAIT` (счётчики уже
  не растут, но закрытие флоу придёт по пропаже сокета).
- Процесс: первая запись `users:(("name",pid=123,fd=4))`.
- Без root `ss` покажет только свои сокеты — коллектор это переживает, UI показывает
  жёлтый баннер `no root: only your sockets`.

### 5.7 `flows.py`

Два уровня: сокеты (для дельт) и флоу (для карты).

```python
@dataclass(slots=True)
class Flow:
    key: str                # f"{remote_ip}|{pid}|{proto}"
    remote: Geo
    process: str
    pid: int | None
    proto: str
    port: int
    tx: int
    rx: int
    tx_rate: float
    rx_rate: float
    first_seen: float
    last_seen: float
    state: str

class FlowTable:
    def update(self, rows: list[SocketRow], now: float) -> list[FlowEvent]
    def stats(self) -> Stats
```

- Дельты: `delta = max(0, new - prev)`; если счётчик уменьшился (сокет переиспользован) —
  считать `new`.
- Закрытие сокета: пропал из выдачи → удалить из набора сокетов потока.
- Жизненный цикл потока:
  - поток **виден**, пока он не простаивал дольше `IDLE_SECONDS = 5` с (простой — это
    «ни одного байта за последние 5 с»);
  - видимый → скрытый: шлётся событие `Closed`, но поток **остаётся в таблице**;
  - скрытый → видимый: шлётся `Opened` **снова**, и следом `Updated` текущего опроса —
    интерфейс снова слышит о потоке;
  - поток, которого не было видно дольше `CLOSE_POLLS = 3` интервалов опроса (то есть у
    которого не осталось сокетов), удаляется из таблицы (событие `Closed`, если он не был
    закрыт раньше — закрывается поток один раз). Интервалы считаются по **реальному**
    времени между опросами, как и скорости: медленный `ss` не закрывает потоки, которые
    ещё живы.
- Скорость: дельта делится на **реальное** время между двумя опросами (а не на
  `poll_ms`), дальше сглаживается скользящим средним (`RATE_ALPHA = 0.5`). Скорость,
  которая опустилась ниже 1 Б/с, обнуляется — это шум, а не трафик.
- `stats()`: суммарные `tx_rate`/`rx_rate`, число флоу, `Counter` стран, топ-5
  `процесс:порт` по rate, счётчик `local` (приватные адреса) и `unknown` (публичные
  адреса, которых нет в базе).
- Порог показа: флоу с `tx+rx == 0` и возрастом > 5 с не рисуется (UDP-«висяки»).

### 5.8 `anim.py`

- `Comet(path, born, ttl=1.2, kind, weight=1)`: голова в `t = (now-born)/ttl`,
  след — 12 предыдущих точек с затуханием.
- Маршрут кометы — дуга большого круга, `PATH_SAMPLES = 160` точек: их хватает, чтобы
  голова двигалась примерно на точку за кадр, и комета не «перепрыгивает» карту.
- След рисуется `Canvas.line` между соседними спроецированными точками, а не отдельными
  точками: длинный маршрут остаётся непрерывной полосой. Точка вне экрана разрывает
  полосу — линия не рисуется поперёк карты.
- Спавн: `Opened` → 1 комета; `Updated` → комета, если `rate > 32 КБ/с`, не чаще
  одной на флоу за 300 мс. Направление: `tx` → out (зелёная), `rx` → in (голубая).
- `Peer(geo, weight, last_seen)`: живёт 10 с после последнего касания.
- Фильтр по процессу: пиры и кометы скрытых потоков **не уничтожаются**, а прячутся —
  `Animator.set_hidden(keys)`. Поэтому фильтр обратим: пиры возвращаются на карту
  сразу, как только фильтр снят.
- Ограничение: не более 200 активных комет, старые вытесняются.

### 5.9 `ui.py`

- `curses.wrapper`, `curs_set(0)`, `nodelay`.
- Поток коллектора + `queue.Queue`; UI-поток только потребляет события. Поток коллектора
  кладёт в очередь кортеж `(events, flows, stats, now)`.
- Раскладка: карта `H-3` строк, 3 строки статуса. При `W < 80` или `H < 24` —
  сообщение «terminal too small».
- Отрисовка: по строкам группируем одинаковые стили в runs, `addstr` на run,
  а не на клетку (иначе 7680 вызовов на кадр).
- Зум: уровень 1 — 360°×180° (весь мир), 2 — 120°×60°, 3 — 30°×20°; центр всегда
  на якоре (без якоря — на `(0, 0)`).
- Суша: растр всего мира считается один раз в размере холста, видимая часть берётся
  из него (выборка по соседям). Исключение — вид, который *точно* совпадает со всем
  миром и центрирован на `(0, 0)`: тогда видная часть и есть растр мира.
- Ресайз: `KEY_RESIZE` → пересчёт viewport и land-маски.
- Режим `--ascii`: та же сетка знакомест, но символ — ASCII-глиф стиля знакоместа
  (`#` суша, `*` пир, `+` голова кометы, `-` след, `O` якорь, пробел — пусто). Снимок в
  этом режиме не содержит ни одного символа блока U+2800.
- `--snapshot PATH --frames N`: отрисовать N кадров с мок-временем и записать
  последний кадр в файл (для тестов и CI, без TTY).
- `--dump PATH`: headless-режим, пишет события `opened|updated|closed` в JSONL
  с геоданными, без curses; выход по `Ctrl-C`.

## 7. Ошибки и деградация

| Ситуация | Поведение |
|---|---|
| Нет `assets/*.mmdb` | сообщение + `make assets`, exit 2 |
| Нет GeoJSON | сообщение + `make assets`, exit 2 |
| Нет TTY | `TUI requires a terminal`, exit 2 |
| `ss` упал | баннер, retry с backoff 1→5 с, последние данные остаются |
| Нет root | жёлтый баннер, работают только свои сокеты |
| Anchor не резолвится | точки без дуг, `anchor: unknown` |
| IP не в базе | страна `--`, точка не рисуется, счётчик unknown |
| Терминал < 80×24 | сообщение, выход по `q` |
| Битый TOML | путь и номер строки, exit 2 |

## 8. Производительность

- Кадр ≤ 60 мс при 200×60 знакомест (400×240 точек).
- CPU ≤ 10 % одного ядра при 12 fps, RSS ≤ 80 МБ.
- Старт ≤ 1 с при тёплом кэше суши.
- `ss`-опрос ≤ 30 мс на типичном десктопе (сотни сокетов).

## 12. Риски

- **UDP-объём не виден** через `ss`: DNS/QUIC только «мигают». M5.
- **Короткие соединения** между опросами 1 Гц могут не попасть. M5.
- **Геолокация города** неточна (датацентры, VPN). Поэтому в подписях страна + ASN.
- **Root** обязателен для полной картины.
- **Braille-шрифт** обязателен; `--ascii` как фолбэк.

## 13. Известные ограничения и оговорки

- **Объём UDP не виден.** У UDP-сокетов в `ss` нет счётчиков байт, поэтому такие потоки
  видны на карте, но без скорости. Нужен eBPF или `nethogs` (в backlog, M5).
- **Опрос раз в секунду.** Сокет, который открылся и закрылся между двумя опросами, может
  не попасть в кадр; короткие всплески трафика усредняются.
- **Город в базе неточен.** Датацентры и VPN отдают координаты соседнего города; надёжны
  страна и номер автономной системы, поэтому в подписях они и показываются.
- **Правило 5 секунд прячет тихих пиров.** Поток, который не передал ни байта дольше 5 с,
  уходит с карты (но остаётся в таблице и может вернуться). Это убирает UDP-«висяки»,
  но скрывает и по-настоящему тихие долгие соединения.
- **Ошибка опроса не убивает карту.** Показатели собираются с задержкой от 1 до 5 секунд
  (backoff), последние собранные данные остаются на экране, в статус-баре горит баннер
  `collector error: ...`.
- **Без root видна только часть трафика.** `ss` без прав администратора показывает
  только сокеты пользователя; программа предупреждает об этом в статус-баре.
- **Браузер сокетов** не видит и не показывает ничего, чего нет в `ss`: только адреса,
  порты, процессы и счётчики байт.
