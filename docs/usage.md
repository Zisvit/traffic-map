# Использование `tmap` — краткий справочник

Подробности установки и запуска — в [README](../README.md). Здесь — что показывает
программа и как её настроить.

## Статус-бар

Статус-бар занимает три последние строки экрана.

**Первая строка — общая картина:**

| Поле | Смысл |
|---|---|
| `↑ 2.4 MB/s` | суммарная скорость отправки по всем потокам машины |
| `↓ 11.8 MB/s` | суммарная скорость приёма |
| `flows 37` | число потоков, которые сейчас на карте (после фильтра) |
| `peers 12` | число разных удалённых адресов на карте |
| `local 3` | число локальных адресов (приватные, loopback) — на карте их нет |
| `unknown 1` | число публичных адресов, которых нет в базе GeoIP |
| `702 pkt/s` | частота пакетов, сглаженная по последним секундам (есть только в режиме `pcap`, когда пакеты идут) |
| `RU DE NL US` | до четырёх стран с наибольшим числом потоков |

**Вторая строка — самые активные потоки** (до трёх), в формате `процесс:порт стрелка скорость`.
Стрелка `↑` — трафик уходит с машины, `↓` — приходит. Скорость — **текущая** скорость
потока: сумма отправленного и принятого за секунду (`tx + rx`), сглаженная по опросам.
Единицы десятичные, с одним знаком после запятой: `9.0 MB/s`, `1.2 MB/s`, `101.0 KB/s`,
`512 B/s`. Это не сумма за всё время жизни потока, а то, что идёт прямо сейчас.

**Третья строка — состояние программы:**

| Часть | Когда появляется |
|---|---|
| `capture error: ...` | захват пакетов не работает: причина и подсказка; программа читает сокеты через `ss` |
| `collector error: ...` | опрос сокетов не удался; данные последнего успешного опроса остаются на карте |
| `no root: only your sockets` | программа читает сокеты (а не пакеты) и работает не от root: видны только ваши сокеты |
| `anchor 203.0.113.7 · RU · geo 10ms` | ваш публичный адрес и страна; `geo` — время поиска (есть, только когда якорь искали автоматически, а не задали вручную) |
| `zoom x3` | текущий зум (кроме первого): множитель к охвату мира |
| `at 52.4N 4.9E` | координаты центра карты (на зуме) |
| `filter: firefox` | активный фильтр по процессу |
| `paused` | карта на паузе |
| `q quit  ? help` | подсказка (всегда в конце) |

Части разделены `·`. Если строка не помещается в ширину терминала, с конца убираются
самые неважные части: сначала подсказка, потом `paused`, потом фильтр.

## Панели

| Клавиша | Панель | Где |
|---|---|---|
| `t` | «busiest flows»: до восьми самых активных потоков — процесс, страна, стрелка и скорость | справа, 30 колонок |
| `l` | подписи стран у пиров (серым, тусклым) | рядом с точкой пира |
| `?` | список клавиш | слева, 46 колонок |

Панели рисуются поверх карты. Клавиша переключает панель: нажали ещё раз — исчезла.

## Зум

Карта центрирована на вашей точке «я» (или на `(0, 0)`, если якорь не найден).

| Клавиша | Охват | Что видно |
|---|---|---|
| `1` | 360° × 180° | весь мир |
| `2` | 120° × 60° | континент и соседи |
| `3` | 30° × 15° | страна и её соседи |
| `+` `=` | ×1,25 за шаг | ближе; середина карты остаётся на месте |
| `-` `_` | ÷1,25 за шаг | дальше |
| `←` `→` `↑` `↓` | — | сдвиг вида на четверть ширины или высоты |
| `c` | текущий | вернуть центр на точку «я» |
| колесо мыши | ×1,25 за щелчок | вокруг точки под курсором: она остаётся на месте |
| `0` | 360° × 180° | весь мир, центр снова на точке «я» |

Зум непрерывный: множитель от 1 до 120 (охват от 360° до 3° по долготе). Колесо зумит
вокруг точки под курсором, `+`/`-` — вокруг середины карты; клавиши `2` и `3` меняют
только масштаб и **не сбрасывают** текущий центр, `1` и `0` показывают весь мир,
`c` возвращает центр на точку «я», не меняя зум.

На зуме от x2 поверх суши рисуются границы стран (если рядом с `land.geojson` лежит
`borders.geojson`), в статусе видны координаты центра, а у краёв карты — стрелки к
пирам, которые остались за кадром. У точки «я» появляется название города.

Суша при зуме рисуется из полигонов под текущий вид, поэтому берега остаются резкими,
а не растягиваются из общего растра мира. Точки пиров лежат на суше.

## Захват трафика

| Режим | Ключ | Что видно | Права |
|---|---|---|---|
| пакеты | `--capture pcap` (по умолчанию) | все пакеты машины: TCP, UDP, IPv6, короткие соединения, искры на карте, `pkt/s` | root или `setcap` на `dumpcap` |
| сокеты | `--capture ss` | сокеты: объём TCP, без объёма UDP; короткие соединения могут теряться | не нужны |

Интерфейс захвата по умолчанию — тот, через который машина ходит в интернет; другой
задаётся ключом `--iface`. Если `pcap` не может начать захват (нет прав или `tshark`),
программа сама переходит на `ss` и показывает в статус-баре `capture error: ...`.

## Фильтр по процессу

Клавиша `f` запрашивает имя процесса. `Enter` применяет фильтр, `Esc` отменяет его,
пустая строка снимает фильтр. Клавиша `Esc` на самой карте тоже снимает фильтр: все
потоки снова на карте, а в статус-баре пропадает строка `filter: ...`.

- На карте остаются только потоки, имя процесса которых содержит введённую строку.
- Пиры скрытых потоков **не теряются**: они просто не рисуются и появляются снова
  сразу, как только фильтр снят.
- Числа `flows` и `peers` в статус-баре считают только то, что на карте. Скорости
  `↑`/`↓`, счётчики `local` и `unknown` считают всю машину.

## Файл конфигурации

Путь: `~/.config/trafficmap/config.toml` (или `$XDG_CONFIG_HOME/trafficmap/config.toml`).

Приоритет: командная строка → переменные `TMAP_*` → файл конфигурации → значения по
умолчанию. Отсутствие файла не считается ошибкой; неизвестный ключ — ошибка с
сообщением и кодом возврата 2.

```toml
fps = 12                 # кадров в секунду
poll_ms = 1000           # интервал опроса коллектора, мс
capture = "pcap"         # "pcap" — пакеты через tshark, "ss" — только сокеты
iface = ""               # интерфейс захвата; пусто — маршрут в интернет
ascii = false            # рисовать карту обычными символами вместо Braille
no_anchor = false        # не искать публичный IP машины
anchor = "52.37,4.90"    # задать точку «я» вручную (широта, долгота)
filter_process = ""      # показывать только потоки этого процесса
city_db = "assets/dbip-city-lite.mmdb"
asn_db = "assets/dbip-asn-lite.mmdb"
land_geojson = "assets/land.geojson"
cache_dir = "~/.cache/trafficmap"
```

Те же поля задаются переменными окружения: `TMAP_FPS`, `TMAP_POLL_MS`, `TMAP_CAPTURE`,
`TMAP_IFACE`, `TMAP_ASCII`, `TMAP_NO_ANCHOR`, `TMAP_ANCHOR`, `TMAP_FILTER_PROCESS`,
`TMAP_CITY_DB`, `TMAP_ASN_DB`, `TMAP_LAND_GEOJSON`, `TMAP_CACHE_DIR`.

## Коды возврата

| Код | Когда |
|---|---|
| `0` | программа отработала штатно: выход по `q`, `Ctrl-C` или `SIGTERM` в режиме `--dump` |
| `2` | ошибка: неизвестный ключ командной строки или битый TOML, нет баз GeoIP, нет карты суши, нет терминала (TUI), не читается запись `--mock`, не пишется результат |

## Формат `--dump` (JSONL)

По одному объекту JSON на строку, без заголовка. Кодировка UTF-8, `ensure_ascii=false`.

```json
{"t": 12.0, "type": "opened", "ip": "1.1.1.1", "port": 443, "proto": "tcp", "process": "curl", "pid": 100, "tx": 1200000, "rx": 40000, "dtx": 0, "drx": 0, "lat": 52.3676, "lon": 4.9041, "country": "NL"}
{"t": 13.0, "type": "updated", "ip": "1.1.1.1", "port": 443, "proto": "tcp", "process": "curl", "pid": 100, "tx": 2400000, "rx": 80000, "dtx": 1200000, "drx": 40000, "lat": 52.3676, "lon": 4.9041, "country": "NL"}
{"t": 20.0, "type": "closed", "key": "1.1.1.1|100|tcp"}
```

| Поле | Смысл |
|---|---|
| `t` | момент события, секунды (монотонные часы) |
| `type` | `opened`, `updated` или `closed` |
| `ip` | удалённый адрес (нормализованный: IPv4-mapped адрес уже развёрнут) |
| `port` | порт удалённой стороны: доминирующий порт потока (порт сокета, который передал больше всего байт) |
| `proto` | `tcp` или `udp` |
| `process` | имя процесса или `null` |
| `pid` | номер процесса или `null` |
| `tx`, `rx` | байты, отправленные и принятые потоком с момента его появления |
| `dtx`, `drx` | байты за последний опрос (для `opened` — нули) |
| `lat`, `lon` | координаты адреса или `null`; для крупных anycast-сетей — основная точка присутствия (карта берёт ближайшую к вам и разносит точки одного города) |
| `country` | код страны ISO 3166-1 alpha-2 или `--` |

У события `closed` остаются только `t`, `type` и `key` — ключ потока имеет вид
`"{ip}|{pid}|{proto}"`.

## Формат `--snapshot` (обычный текст)

Файл состоит из строк карты и трёх строк статус-бара. В обычном режиме карта набрана
символами Braille (U+2800), в режиме `--ascii` — обычными символами ASCII
(`#` — суша, `*` — пир или искра пакета, `+` — голова кометы, `-` — след, `O` — точка «я»,
пробел — море).
Управляющие последовательности в файле нет: это чистый текст в UTF-8.

```
↑ 1.2 MB/s   ↓ 9.1 MB/s   flows 4   peers 4   local 1   unknown 1   US AU
firefox:443 ↓9.0 MB/s · curl:443 ↑1.2 MB/s · unknown:53 ↓101.0 KB/s
no root: only your sockets · anchor 198.51.100.42 · NL · geo 0ms
```

## Журнал и диагностика

По умолчанию программа молчит: в статус-баре видно только то, что случилось с захватом
или опросом сокетов (баннеры `capture error: ...` и `collector error: ...`). Ключ
`--verbose` включает журнал программы: сообщения пишутся в `stderr`, а не в стандартный
вывод, — карта на экране от этого не портится. По умолчанию уровень журнала — `INFO`,
то есть тишина.

```bash
.venv/bin/tmap --verbose                 # журнал в stderr
.venv/bin/tmap --verbose --mock tests/fixtures/mock.jsonl   # демо с журналом
```

## Служебный файл

`trafficmap.service` — юнит systemd. Внимание: `tmap` рисует в терминале, поэтому
служба без `TTYPath` не сможет показать карту: запускайте программу из обычной
оболочки либо укажите в юните `TTYPath=/dev/tty1`.
